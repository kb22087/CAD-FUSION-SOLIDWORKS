# CAD Practice & Engineering Designs

Welcome to my **CAD Practice & Engineering Designs** repository! ⚙️

This repository documents my journey in Computer-Aided Design (CAD) as a Mechanical Engineering student. It contains practice models, mechanical components, engineering drawings, and official design projects created to develop my skills in 3D modelling, mechanical design, and engineering visualization.

## 🎯 Objectives

- Develop proficiency in CAD software and 3D modelling.
- Practise creating mechanical components using sketches, features, and parametric modelling.
- Apply engineering concepts to practical design problems.
- Maintain a structured record of CAD practice and completed projects.
- Build a portfolio demonstrating my technical development and design capabilities.

## 🛠️ Tools & Software

- **Autodesk Fusion 360** — Primary CAD and 3D modelling software.
- Additional CAD, simulation, or engineering tools will be documented as they are used.

## 📂 Repository Contents

The repository is organized into the following categories:

| Directory | Contents |
|---|---|
| `Practice-Models/` | CAD exercises, geometric models, and individual mechanical components. |
| `Engineering-Drawings/` | Technical drawings, dimensions, and drawing sheets. |
| `Official-Projects/` | Models and design work developed for official projects, competitions, or academic activities. |
| `Assemblies/` | Multi-component assemblies and mechanical mechanisms. |
| `Renders-and-Screenshots/` | Model previews, CAD screenshots, and rendered views. |

*Directories will be added as the repository grows.*

## 📐 File Formats

Depending on the project, files may include:

- `.f3d` — Fusion 360 design files.
- `.f3z` — Fusion 360 archive files for supported multi-component designs.
- `.step` / `.stp` — STEP files for CAD interoperability.
- `.stl` — Mesh files for 3D printing and visualization.
- `.pdf` — Engineering drawings and documentation.
- `.png` / `.jpg` — Model previews and screenshots.

## 📌 Model Documentation

Where applicable, individual projects will include:

- Project name and purpose.
- CAD software used.
- Key design features and modelling techniques.
- Relevant dimensions and engineering considerations.
- Screenshots or rendered views.
- Exported files and technical drawings, where available.

## 🚀 Progress & Learning

This repository will evolve alongside my engineering journey. Each model represents an opportunity to improve geometric modelling, design intent, feature planning, precision, and the practical application of mechanical engineering principles.

The goal is not just to create 3D models, but to understand the engineering behind them.
