# CAD Practice Models

This directory contains CAD practice models developed as part of my journey in Mechanical Engineering. The models are created primarily using **Autodesk Fusion 360** to strengthen my understanding of 3D modelling, geometric construction, and mechanical component design.

## 🎯 Purpose

- Practise and improve 3D CAD modelling skills.
- Develop proficiency in sketching, feature-based modelling, and parametric design.
- Understand the geometry and structure of mechanical components.
- Explore modelling workflows using features such as Extrude, Revolve, Sweep, Loft, Fillet, Chamfer, and Hole.
- Build consistency, precision, and confidence in engineering design.

## 📂 Contents

This directory may include:

- **Basic Geometry:** Fundamental shapes and sketch-based exercises.
- **Mechanical Components:** Mounting plates, brackets, bosses, shafts, and other individual parts.
- **Feature Practice:** Models exploring specific CAD tools and operations.
- **Complex Geometry:** Components involving multiple features and more advanced modelling techniques.
- **Model Previews:** Screenshots and rendered views of completed designs.

## 🛠️ Software & File Formats

**Primary software:** Autodesk Fusion 360

Depending on the exercise, files may include:

| Format | Purpose |
|---|---|
| `.f3d` | Native Fusion 360 design files |
| `.step` / `.stp` | Exchange of 3D solid models between CAD applications |
| `.stl` | Mesh exports for 3D printing and visualization |
| `.pdf` | Technical drawings, where applicable |
| `.png` / `.jpg` | Screenshots and model previews |

## 📌 Modelling Approach

Each model is an opportunity to practise design intent, feature sequencing, geometric accuracy, and efficient use of CAD tools.

Where relevant, dimensions, modelling techniques, and screenshots will be included to document the construction process and the features explored.

These models are primarily intended for practice and learning rather than manufacturing, unless explicitly documented otherwise.

## 📈 Learning & Progress

This collection will grow as I explore new modelling techniques, improve existing workflows, and take on increasingly challenging components.

The objective is to develop not only the ability to create 3D geometry, but also the engineering intuition needed to design components with clarity, precision, and purpose.
